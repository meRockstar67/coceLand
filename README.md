# coceLand

Кастомный Minecraft-лаунчер: сам качает нужную версию + NeoForge, докачивает моды из конфига и подставляет сервер в мультиплеере.

## Запуск (для разработки)

Нужен установленный Node.js (18+) и Java (для установки NeoForge).

```bash
npm install
npm start
```

При первом запуске откроется окно логина Microsoft — это обязательно (лицензионный аккаунт нужен для запуска игры).

## Сборка .exe (обычная, без публикации)

```bash
npm run build
```

Готовый `coceLand-Setup-x.x.x.exe` появится в папке `dist/`. Это нормальный установщик (NSIS) — спросит папку установки, поставит ярлык на рабочий стол и в меню Пуск.

## Автообновление — как это работает

Обновления идут через **GitHub Releases**. Схема такая:

1. Создаёшь на GitHub приватный или публичный репозиторий, например `coceland-launcher`.
2. В `package.json` в блоке `build.publish` меняешь `owner` на свой GitHub-логин (репозиторий уже указан как `coceland-launcher`, можно оставить).
3. Генерируешь GitHub Personal Access Token (Settings → Developer settings → Tokens, права `repo`) и кладёшь его в переменную окружения перед сборкой:
   ```bash
   set GH_TOKEN=твой_токен       (Windows cmd)
   $env:GH_TOKEN="твой_токен"    (PowerShell)
   ```
4. Поднимаешь версию в `package.json` (например `1.0.0` → `1.0.1`) и запускаешь:
   ```bash
   npm run publish
   ```
   Это соберёт `.exe` и сразу зальёт его в новый Release на GitHub вместе со служебным файлом `latest.yml` (по нему лаунчер понимает, что вышла новая версия).

5. У всех, у кого уже установлен coceLand, при запуске лаунчер сам проверит GitHub Releases, скачает обновление в фоне и покажет кнопку **"ОБНОВИТЬ И ПЕРЕЗАПУСТИТЬ"** — жмут её, лаунчер перезапускается уже на новой версии.

То есть тебе для апдейта нужно только: поднять версию в `package.json` → `npm run publish`. Всё остальное автоматом.

**Важно:** первую версию (саму первую установку) всем придётся ставить вручную через `.exe` из `dist/` — автообновление работает только "вперёд", от уже установленной версии к новой.

**Про GH_TOKEN:** он нужен только тебе на твоей машине при сборке/публикации, конечным игрокам ничего вводить не надо — они просто открывают лаунчер.

**Windows SmartScreen:** так как exe не подписан платным сертификатом, при первом запуске Windows может показать предупреждение "Неизвестный издатель" — это нормально для инди-инструментов, жмут "Подробнее → Выполнить в любом случае". Если это критично, могу позже подсказать по недорогим вариантам подписи кода.

## Конфиг — `config.json`

**Важно:** лаунчер при каждом запуске сам скачивает свежий `config.json` из этого репозитория (ветка `main`, файл в корне). Значит, чтобы обновить список модов/сервер/версию у всех, кто уже установил coceLand, НЕ нужно пересобирать `.exe` и просить всех обновляться — достаточно обновить `config.json` прямо на GitHub (через "Add file → Upload files" или "Edit"), и у всех игроков при следующем запуске подтянется новый список автоматически.

Если у игрока нет интернета в момент запуска - лаунчер использует последнюю успешно скачанную копию, а если её вообще ни разу не было - вшитую в лаунчер версию как запасной вариант.

Пересборка `.exe` (`npm run build`/`npm run publish`) нужна только когда меняется сам код лаунчера (UI, логика запуска), а не список модов.

```json
{
  "minecraftVersion": "1.21.1",
  "modLoader": "neoforge",
  "neoforgeVersion": "21.1.100",
  "ram": { "min": "2G", "max": "4G" },
  "server": { "name": "coceLand", "ip": "play.example.com" },
  "mods": [
    { "name": "example-mod.jar", "url": "https://example.com/example-mod.jar" }
  ]
}
```

- `minecraftVersion` — версия игры.
- `neoforgeVersion` — **важно проверить точную версию** на https://projects.neoforged.net/neoforged/neoforge — сейчас там стоит placeholder, версия может не совпадать с 1.21.1.
- `server.ip` — сейчас заглушка, пришли реальный адрес — впишу.
- `mods` — сейчас пустой пример. Пришли список модов (ссылки на .jar, например с Modrinth/CurseForge, или прямые ссылки на твой B2), добавлю сюда.

## Прокси для модов с Modrinth (обход блокировки в РФ)

Modrinth и CurseForge заблокированы в РФ, поэтому файлы модов качаются не напрямую, а через свой Cloudflare Worker — он лежит в папке `cloudflare-worker/` и полностью отдельный от других твоих проектов (renah0cki и т.д. не трогает).

### Как задеплоить (один раз)

1. Установи Wrangler (CLI для Cloudflare Workers):
   ```bash
   npm install -g wrangler
   ```
2. Залогинься в **свой** Cloudflare-аккаунт:
   ```bash
   wrangler login
   ```
   Откроется браузер — подтверди вход.
3. Перейди в папку воркера и задеплой:
   ```bash
   cd cloudflare-worker
   wrangler deploy
   ```
4. В выводе будет ссылка вида `https://coceland-mod-proxy.ТВОЙ_ПОДДОМЕН.workers.dev` — это и есть твой прокси-адрес. Сохрани его.

Если такого имени поддомена ещё не было в твоём аккаунте, Cloudflare попросит один раз задать subdomain (workers.dev) при первом деплое — это нормально, делается один раз для всех твоих воркеров.

### Как этим пользоваться

Воркер принимает только ссылки с `cdn.modrinth.com` (и `api.modrinth.com`), формат:
```
https://coceland-mod-proxy.ТВОЙ_ПОДДОМЕН.workers.dev/mod?url=<закодированная ссылка с cdn.modrinth.com>
```

Чтобы получить прямую ссылку на файл мода на Modrinth (её и нужно закодировать):
- Открой страницу мода на modrinth.com → вкладка Versions → нужная версия → правый клик на кнопку Download → "Копировать адрес ссылки".
- Это и есть `cdn.modrinth.com/...` ссылка, которую нужно подставить в `url=` (в закодированном виде).

Когда пришлёшь мне список модов из твоей сборки (названия или ссылки на Modrinth), я сам оберну их в такой формат и впишу в `config.json` — вручную кодировать URL не придётся.

## Известные риски (не проверено вживую, т.к. у меня нет сети/Java для теста)

- Название параметра для NeoForge в `minecraft-launcher-core` (`opts.forge`) может не подхватывать installer NeoForge на 100% автоматически в зависимости от версии либы — если при первом запуске упадёт на этом шаге, скинь мне текст ошибки, поправлю.
- Формат `servers.dat` через `prismarine-nbt` — стандартный, но если Minecraft не увидит сервер в списке, тоже скажи, разберёмся.
